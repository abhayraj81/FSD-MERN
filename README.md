## Overview

This repository is a personal, hands-on learning log for **Full-Stack Development (FSD)** — building up sequentially from static markup to a full MERN application. Each folder is self-contained and numbered/labelled to reflect the order concepts were learned in, so the commit history and file order double as a topic-by-topic curriculum.

- 🧱 **Frontend fundamentals** — semantic HTML, CSS layout systems, Bootstrap components
- ⚙️ **Core JavaScript** — language mechanics, array methods, DOM manipulation, events
- 🍃 **Database layer** — MongoDB queries, aggregation pipelines, CRUD operations
- 🚂 **Backend (in progress)** — Express.js server & REST API foundations
- ⚛️ **Frontend framework** — React 19 with hooks, context, routing, and component composition

## Getting Started

<img src="https://img.shields.io/badge/Git-F05032?style=flat-square&logo=git&logoColor=white" alt="Git" />
<img src="https://img.shields.io/badge/Node.js-339933?style=flat-square&logo=nodedotjs&logoColor=white" alt="Node.js" />

**1. Clone the repository**

```bash
git clone https://github.com/abhayraj81/FSD-MERN.git
cd FSD-MERN
```

**2. Frontend fundamentals — `HTML-CSS-JS/`**

No build tools or dependencies required. Open any `.html` file directly in a browser, or serve the folder with a lightweight static server (e.g. the VS Code "Live Server" extension) for pages that use relative asset paths.

**3. MongoDB — `MongoDB/`**

Run the `.js` files through the `mongosh` shell or MongoDB Compass against a local instance or an Atlas connection string:

```bash
mongosh "your-connection-string" < "MongoDB/1 MongoDbQueries.js"
```

**4. Express server — `Express/`**

```bash
cd Express
npm install
node index.js
```

**5. React app — `React/myFirstApp/`**

```bash
cd React/myFirstApp
npm install
npm run dev
```

Then open the local URL Vite prints in the terminal (typically `http://localhost:5173`).

Other available scripts:

```bash
npm run build     # production build
npm run preview   # preview the production build locally
npm run lint      # run ESLint
```
