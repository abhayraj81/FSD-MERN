## Repository Structure

```
FSD-MERN/
├── HTML/           Markup, tables, forms, media, hyperlinks
├── CSS/            Selectors, flexbox, pseudo-elements, responsive design
├── Bootstrap/      Grid system, components, responsive layouts
├── JS/             Core JavaScript — from variables to array methods
├── DOM-JS/         DOM manipulation & event handling
├── MongoDB/        Queries, aggregation, and CRUD operations
├── Assignments/    Applied practice tasks
└── Images/         Static assets used across exercises
```

## Getting Started

<img src="https://img.shields.io/badge/Git-F05032?style=flat-square&logo=git&logoColor=white" alt="Git" />

```bash
git clone https://github.com/abhayraj81/FSD-MERN.git
cd FSD-MERN
```

No build tools or dependencies required for the `HTML/`, `CSS/`, `Bootstrap/`, `JS/`, and `DOM-JS/` folders — open any `.html` file directly in a browser.

For `MongoDB/`, run the `.js` files through the `mongosh` shell or MongoDB Compass with a local/Atlas connection.
